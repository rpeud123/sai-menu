# 사이 웹 개발 V1

포함 기능:
- 스플래시 애니메이션
- 손님 메뉴판
- AI 취향 추천
- 가격대 분류
- 점수 및 S/A/B/C 등급
- 원가율 표시 및 원가 계산기
- 관리자 메뉴 편집
- JSON 백업/복원
- 시그니처 8종 최신 데이터
- 술별 한줄평·스토리·편지 필드
- 얼그레이 하이볼 삭제 반영

실행:
- 웹서버에 폴더 전체 업로드
- 로컬에서는 `python -m http.server` 후 접속
- 손님 화면: index.html
- 관리자 화면: admin.html

주의:
- 실제 로고 파일은 아직 없어 텍스트 로고로 구성했습니다.
- 실제 구매 원가는 0원으로 두었습니다. 관리자 페이지에서 입력해야 정확한 원가율이 계산됩니다.
- 현재 관리자 수정은 같은 브라우저 LocalStorage에만 저장됩니다. 운영 전 서버 DB와 로그인 연결이 필요합니다.
